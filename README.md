# ML Algorithm Learning Lab

## About the Project
ML Algorithm Learning Lab is an interactive web application designed to help students understand machine learning algorithms through step-by-step calculations, visualizations, and practical simulations.

## Features
- Step-by-step algorithm explanations
- Interactive graphs and visualizations
- Custom input data
- Predictions and calculations
- Previous, Next, Start Over, and Show All controls
- Interactive simulations

## Algorithms Covered
1. Simple Linear Regression
2. Polynomial Regression
3. Logistic Regression
4. K-Nearest Neighbours (KNN)
5. K-Means Clustering
6. K-Medoids Clustering
7. DBSCAN
8. AdaBoost
9. Hidden Markov Model (HMM)

## Technologies Used
- HTML
- CSS
- JavaScript
- SVG for visualizations

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Select an algorithm.
4. Enter the data and click **Solve step by step**.
5. Use the navigation buttons and simulation sliders to explore the algorithm.

## Deployment
This project can be hosted using GitHub Pages.

## Purpose
The purpose of this project is to make machine learning concepts easier to understand through interactive learning and visual examples.
